# 迷途者 · 手机适配联机桌游 v2.0

一个可通过浏览器在手机、平板和电脑上游玩的双人在线桌游原型。服务端使用 Node.js + Express + WebSocket；不需要客户端安装应用。

## 本地运行

需要 Node.js 18 或更高版本。

```bash
npm install
npm start
```

打开 `http://localhost:3000`。玩家 A 创建房间，把房间码发给玩家 B；玩家 B 在同一网站输入房间码加入。只有房主可以开始。

## 部署到公网（Render）

1. 将整个项目目录上传到 GitHub 仓库。
2. 在 Render 新建 **Web Service** 并连接仓库。
3. Build Command：`npm install`
4. Start Command：`npm start`
5. 部署成功后，将 Render 提供的 HTTPS 地址分享给朋友。页面会自动通过 WSS 连接。
6. 可用 `https://你的域名/health` 检查服务状态。

也可以部署到支持长连接 WebSocket 的 Node.js 主机。不要把它部署为纯静态网站，因为联机需要运行 `server.js`。

## 已实现的游戏循环

- 双人房间码、实时同步、断线后同浏览器 session token 重连。
- 手机优先的自适应 8×8 棋盘、清晰地形配色、触控按钮和安全区布局。
- 开局展示地图 8 秒；之后只向玩家展示自己已经探索或用卡牌查看的格子。
- 玩家秘密目标、私有手牌、掷骰移动、回合结束、生命/水/木材/矿石/金币。
- 八种地形：机关、资源、中央区、宝藏、危桥、交易处、草地、锻造台。
- 多种机关事件、卡牌效果、陷阱/封路、武器与护盾、战斗、猜测目标、转移目标。
- 毒圈逐轮收缩；圈外探索及回合结束会造成伤害。
- 德国扑克：使用 32 张德国花色牌组（7、8、9、10、骑士、王后、国王、A），每人模拟发 5 张并按高牌、一对、两对、三条、顺子、同花、葫芦、四条、同花顺的牌型顺序比较；胜者获得 1 目标点。该项目将“德国扑克”具体化为一个五张牌型比较迷你游戏，因为当前提供的规则文本没有定义独立扑克回合的完整发牌/下注流程。
- 目标分达到 12 点获胜；包含 21 种目标定义与主要进度检查。

## 重要说明：仍需按正式规则核对

本项目是可部署的持续开发版本，不应视为已通过完整规则验收。当前对复杂规则做了可玩化解释，尤其是卡牌细节、部分秘密目标进度和德国扑克的牌型规则。若你有明确的“德国扑克”流程（如是否需要下注、换牌、先后手、具体牌型大小），应据此替换当前简化实现。

目前房间和对局状态保存在服务器内存中；服务重启会清空对局。断线重连 token 保存在当前浏览器的 `sessionStorage`，更换浏览器/设备无法恢复原身份。正式上线前建议增加持久化存储、房间密码/速率限制、自动化规则测试、服务端监控和异常恢复。

## 项目结构

- `server.js` — 游戏规则、房间管理、WebSocket 服务
- `public/index.html` — 手机适配的游戏界面
- `package.json` — 依赖与启动命令
- `render.yaml` — Render 部署配置
- `.gitignore` — 忽略依赖和环境文件
